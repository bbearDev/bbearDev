## 주요 기능 자세히

### 🔗 치지직 닉네임 연동


서버에 처음 들어오면 자신의 치지직 채널을 연결합니다. 
그 다음부터는 마인크래프트 아이디가 아니라 **방송 닉네임**이 서버 전체에 표시됩니다.

- 채팅, 머리 위 이름표, Tab, 입장·퇴장·사망 메시지 전부 채널명으로 표시
- `/tp 아이곰` 처럼 **바닐라 명령어에서도 채널명이 그대로 통합.** 
- 닉네임에 띄어쓰기가 들어 있거나 대소문자를 틀려도 인식됩니다

```
/닉네임 연동 <채널ID>     # 내 치지직 채널 연결
/닉네임 목록              # 연동 현황 (운영자)
/닉네임 찾기 <검색어>      # 닉네임·아이디로 검색 (운영자)
```

### 💸 후원 API


스트리머가 `/스트리머 연결` 한 번으로 치지직 계정을 연결하면, 방송 중 들어온 후원이 **실시간으로 서버에 전달**됩니다. 금액대별로 원하는 이벤트를 미리 지정해 둘 수 있습니다.

| 후원 금액 | 예시 이벤트 |
|:--|:--|
| 1,000원 | 서버 전용 코인 지급 |
| 5,000원 | 스트리머에게 랜덤 몹 습격 |
| 50,000원 | 스트리머를 감옥에 수감 |
| 100,000원 | 전원에게 우편으로 아이템 지급 |


- 인벤토리가 꽉 찬 상태로 후원 보상이 와도 **우편함으로 안전하게 들어갑니다**
- `/스트리머 테스트후원` 으로 실제 후원 없이 보상 설정을 미리 점검할 수 있습니다

```
/스트리머 연결 [닉네임]       # 치지직 계정 연결 (본인 인증 포함)
/스트리머 연결해제
/스트리머 목록
/스트리머 테스트후원 <채널ID> <금액> [후원자명] # 후원 테스트 (운영자)
```

### 🏘️ 부동산 


운영자가 구역을 지정해 매물로 등록하면, 플레이어가 **돈을 주고 사고 세를 놓습니다.**

- **구매 / 판매**: 마커를 클릭해 가격을 확인하고 그 자리에서 구매. 판매하면 등록 당시 지형으로 되돌릴 수도 있습니다
- **임대**: 집주인이 세입자를 초대하고, 세입자는 수락 후 그 구역에 건축·상호작용 권한을 얻습니다. 임대료는 자동 징수되고 개별 조정도 가능합니다
- **보호**: 주인·세입자가 아니면 블록을 부술 수 없고, 폭발·투사체·몹 밟기 등 접근이 막힙니다
- **목록 GUI**: 등록된 매물을 클릭 한 번으로 이동·편집·삭제 (운영자)

```
/부동산 등록
/부동산 관리        # 내 부동산 GUI (주인)
/부동산 판매
/부동산 확인        # 내가 가진 부동산 보기
/부동산 임대정보     # 내 임대 현황 (세입자)
/부동산 수락 <초대ID>
```

### 📜 퀘스트

의존성: LuxDialogues

NPC에게 말을 걸면 대화창이 열리고, **선택지에 따라 이야기가 갈라집니다.**

- 대사·선택지·보상을 **전부 인게임 GUI에서 제작**합니다. 파일을 직접 편집할 필요가 없습니다
- **조건 관문**: 특정 아이템·소지금·권한·선행 퀘스트를 갖춰야만 보이는 선택지를 만들 수 있습니다.<br/>조건을 만족하면 아이템과 돈이 실제로 차감되고, 실패하면 원래대로 되돌아갑니다

```
/퀘스트 목록              # 진행 중인 퀘스트 확인
/퀘스트 편집              # 제작 GUI (운영자)
```

### 🏃 점프맵 — 파쿠르 코스

시작 블록을 밟으면 "이 코스를 시작할까요?" 안내가 뜹니다. 시작하면:

- **인벤토리가 통째로 보관**되고 손에는 두 개의 아이템만 남습니다 — *체크포인트 복귀*와 *탈출*
- 떨어져 죽어도 짐을 잃지 않고 마지막 체크포인트에서 다시 시작합니다 (사망 시 드랍·경험치 손실 없음)
- 완주하면 **그 자리에서 폭죽이 터지고 보상이 지급**됩니다. 개인 최고 기록도 갱신됩니다
- 코스 진행 중에는 상자를 열 수 없어 아이템 반입 등이 막힙니다

```
/점프맵 목록          # 코스 목록 GUI
/점프맵 생성 시작 <이름>   # 코스 제작 (운영자)
```

### 🎒 가방 & 📮 우편함


**가방** — 특정 아이템으로 만든 가방을 우클릭하면 **휴대용 인벤토리**가 열립니다. 갈색(3줄)·분홍(6줄) 등 종류별로 용량이 다르고, 내용물은 가방 하나하나에 개별 저장됩니다. 복제 방지 규칙이 걸려 있어 아이템 복사에 쓸 수 없습니다.

**우편함** — 플레이어에게 아이템과 메시지를 보낼 수 있습니다. 운영자는 조건을 걸어 **전체 일괄 발송**도 가능합니다 (접속자만, 특정 월드만 등).

```
/가방              # (가방 아이템 우클릭으로도 열림)
/우편함            # 받은 우편 확인
/우편함 작성        # 보낼 사람 선택 GUI
```

### 🏷️ 칭호

의존성: CustomNameplates

GUI에서 아이콘을 클릭해 칭호를 장착합니다. 글자 칭호와 커스텀 이미지를 모두 지원하고, 머리 위 이름표에 반영됩니다.<br/>
설정에 따라 채팅 닉네임 앞에도 넣을 수 있습니다.
```
/칭호 			# 칭호 목록
/칭호 확인		# 본인의 칭호 확인
```

## 🚔 운영 도구

| 기능 | 설명 |
|:--|:--|
| **채팅 제어** | 월드별로 채팅을 분리하고 반경 제한을 걸 수 있습니다.<br/> 공지 때는 `/채팅 잠금`으로 전체를 조용하게, 확성기 아이템을 쓴 사람만 발언권을 얻습니다 |

| **몹 소환** | 프리셋 기반 랜덤 몹 습격. 확률·최소/최대 마릿수를 개별 지정할 수 있어 "엔더드래곤은 최대 1마리" 같은 구성이 가능합니다 |

## 의존성 플러그인

Bbear는 의존성 플러그인이 있어야 동작합니다.<br/> 없으면 해당 기능만 조용히 꺼집니다.

| 플러그인 | Bbear가 쓰는 곳 |
|:--|:--|
| **PlaceholderAPI** | 모든 모듈의 정보를 다른 플러그인에 노출 (필수) |
| **Nexo, Itemsadder** | 커스텀 아이템 — 가방·감옥권·귀환권·확성기·칭호 아이콘 |
| **CustomNameplates** | 머리 위 이름표에 치지직 닉네임·칭호 표시 |
| **LuxDialogues** | 퀘스트 NPC 대화 UI |
| **Citizens** | 퀘스트·감옥 NPC |
| **WorldGuard / FAWE** | 부동산 구역 보호와 지형 스냅샷 복원 |
| **MythicMobs** | 몹 소환 프리셋의 커스텀 몹 |
| **ModelEngine** | 보상 상자 트리거 모델 |
| **Vault** | 부동산·퀘스트의 소지금 처리 |
| **ProtocolLib** | 명령어 자동완성에 닉네임 주입 |
| **TAB** | 표시 이름 호환 |

## 기술 개요

<details>
<summary>펼쳐 보기</summary>

| 항목 | 값 |
|:--|:--|
| 플랫폼 | Paper 1.21.4 (API 1.21) |
| 언어 | Java 21 |
| 빌드 | Gradle (paperweight-userdev) |
| 구성 | 기능 모듈 16개 · 클래스 429개 · 약 63,700줄 |
| 테스트 | JUnit 5 + Mockito, 자체 테스트 모듈 1,600여 개 |
| 현재 버전 | v1.7.0 |

**설계 방향**

- **모듈 단위 격리** — 각 기능은 자체 생명주기(활성/비활성/리로드)를 갖고 서로를 직접 호출하지 않습니다. 한 모듈이 실패해도 나머지는 정상 동작합니다.
- **연동 플러그인은 전부 선택 사항** — 런타임에 존재를 확인하고, 없으면 해당 기능만 자동으로 비활성화됩니다. 특정 플러그인 버전에 묶이지 않도록 느슨하게 연결했습니다.
- **채팅 장식 우선순위 예약제** — 확성기·구독티콘·닉네임·칭호가 항상 같은 순서로 렌더링되도록 우선순위를 코어에서 관리합니다.
- **무중단 리로드** — 대부분의 설정 변경은 서버 재시작 없이 `/bbear reload`로 반영됩니다

</details>
